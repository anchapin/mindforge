# MindForge Sprint Plan: v1.0.1 Patch

## Goal
Stabilize the system for v1.0.1 release by addressing agent reliability, tool authorization, performance bottlenecks, and frontend testability.

## Wave 1: Foundation & Security
*Target: Day 1-2*

### 1. JSON Recovery Rollout ([#138](https://github.com/anchapin/mindforge/issues/138))
- **Objective**: Ensure agents handle malformed JSON gracefully.
- **Approach**: Refactor CMO, Researcher, and Engineer agents to use `parse_with_recovery`.
- **Validation**: Mock malformed LLM responses and verify recovery/retry.

### 2. Tool Permission Wiring ([#139](https://github.com/anchapin/mindforge/issues/139))
- **Objective**: Enforce agent-level authorization for tool calls.
- **Approach**: Pass `agent_role` from `supervisor.py` to `BaseTool.execute`.
- **Validation**: Test calling a "research" tool from the "engineer" agent when not authorized.

### 3. Shared Routing Logic ([#141](https://github.com/anchapin/mindforge/issues/141))
- **Objective**: Single source of truth for task classification.
- **Approach**: Move `TASK_TYPE_RULES` and `classify_task_type` to `backend/agents/routing.py`.
- **Validation**: Verify routing consistency in `store.py` and `supervisor.py`.

## Wave 2: Frontend & E2E Stability
*Target: Day 2-3*

### 4. data-testid Injection ([#140](https://github.com/anchapin/mindforge/issues/140))
- **Objective**: Stabilize Playwright tests.
- **Approach**: Add `data-testid` to all primary buttons, inputs, and modals.
- **Validation**: Update E2E tests to use IDs and confirm they pass reliably.

## Wave 3: Performance & Resilience
*Target: Day 3-5*

### 5. Integration Retry Logic ([#144](https://github.com/anchapin/mindforge/issues/144))
- **Objective**: Handle transient network errors.
- **Approach**: Implement exponential backoff in `BaseTool` or specific integration clients.
- **Validation**: Simulate 503 errors and verify retries.

### 6. Async PGLite Migration ([#142](https://github.com/anchapin/mindforge/issues/142))
- **Objective**: Unblock the event loop.
- **Approach**: Swap `sqlite3` for `aiosqlite`.
- **Validation**: Run memory-intensive task benchmarks.

### 7. SupervisorRunner Pooling ([#143](https://github.com/anchapin/mindforge/issues/143))
- **Objective**: Reduce task startup latency.
- **Approach**: Pre-compile LangGraph instances at startup.
- **Validation**: Compare `/api/tasks` response times before/after.

## Quality Gates
- All changes must pass `make lint` and `make test`.
- E2E tests must be run via `npx playwright test`.
- All security primitives (HMAC, Safe YAML) must remain intact.
